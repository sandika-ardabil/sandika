# Sandika — بستهٔ وب انجمن صنفی اردبیل

این بسته یک سایت ایستای فارسی است. همهٔ صفحه‌ها و assetهای نسخهٔ پایه نگه داشته شده‌اند؛ رابط ورود در `login.html` با طراحی شیشه‌ای آبی بازآرایی شده است.

## اجرا
- پوشه را روی میزبانی static قرار دهید یا از ریشهٔ پروژه اجرا کنید: `python -m http.server 8000` و سپس `http://localhost:8000/intro.html` را باز کنید.
- برای ورود آزمایشی با رمز، شناسه و رمز هر دو `admin` هستند.
- برای OTP، روش «ورود با کد یکبارمصرف» را انتخاب کنید، ایمیل/شماره را وارد کنید و کد چهاررقمی نمایش‌داده‌شده در همان صفحه را وارد کنید.

## وضعیت احراز هویت
OTP در این نسخه **کاملاً شبیه‌سازی‌شده و سمت کاربر** است؛ ارسال پیامک یا ایمیل، تأیید هویت واقعی، محدودسازی درخواست‌ها در سرور و امنیت production را فراهم نمی‌کند. کد روی صفحه نشان داده می‌شود تا جریان رابط کاربری قابل آزمایش باشد. برای استفادهٔ واقعی، endpoint امن و سرویس SMS/Email یا Supabase Auth را پیکربندی کنید. از این روش برای حساب‌های واقعی/اطلاعات حساس استفاده نکنید.

ورود موفق، کلیدهای مورد انتظار سایت (`sandika_user` و `sandika_authenticated`) را در Storage می‌نویسد تا سازگاری `auth.js` و گاردهای فعلی حفظ شود. احراز هویت client-side به‌تنهایی کنترل دسترسی امن نیست.

## محتویات
`index.html`, `intro.html`, `login.html`, `auth.js`, صفحات انجمن و مکاتبات، `assets/`, `CHANGELOG_PHASE*.txt`. داده‌های Supabase، اگر در کد پایه وجود داشته باشد، دست‌نخورده نگه داشته شده؛ در این بسته اعتبارنامه یا کلید واقعی جدیدی اضافه نشده است.
